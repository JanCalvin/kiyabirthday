COLLECT YOUR BIRTHDAY WISHES

Cara menjalankan:
1. Extract ZIP.
2. Buka folder birthday_wishes_game.
3. Klik dua kali index.html (Chrome/Edge/Firefox).
4. Untuk dibuka lewat HP, upload folder ini ke hosting static seperti GitHub Pages, Netlify, atau Vercel lalu buka URL-nya dari browser HP.

Kontrol:
- Laptop: Arrow kiri/kanan atau A/D untuk bergerak, Space/Arrow atas/W untuk lompat.
- HP: tombol kiri, kanan, dan lompat di layar. Putar HP ke landscape untuk pengalaman terbaik.

Kustomisasi pesan:
Buka index.html, cari bagian `const wishes = [...]` untuk mengubah 5 pesan.
Teks ucapan terakhir dapat diubah di bagian `finalScreen`.

Catatan:
Game ini memakai HTML Canvas, CSS, dan JavaScript murni. Tidak memerlukan instalasi library atau koneksi internet untuk menjalankan game secara lokal.
